💡 Standalone version. This is a static template of a virtual office that runs in Muse. Task data here lives in your own browser's localStorage — it is not live office data. The live office cannot be shared through a public link (it is a fullstack app whose data is tied to the owner's account).

Task Board

Task letters in motion: Backlog → In progress → Waiting for owner → Done. Only the owner marks a task Done. Drag cards between columns, or use the move menu on each card (on mobile). Changes save automatically in this browser.

⚠️ Hard rule — COMPLIANCE: the office never processes sensitive case content — general administration only. Case work happens only in the dedicated compliance chat.

Recruit Panel

The office manager (Muse) may hire a new skill or agent when a task needs expertise the office does not have yet. Free hires go live immediately and are reported to the owner; paid hires wait for the owner's approval.

1

Search

The manager looks for a matching skill in the catalog or hiring bank, then reads its SKILL.md until it is understood.

2

Check

Validate the frontmatter, scan for safety, and make sure no code or installer is run from the source repo.

3

Install

The skill is copied verbatim into the office library together with its skill.yaml, INSTALL-NOTES.md, and ATTRIBUTION.md.

4

Report

Every hire is reported to the owner. Free hires go live at once; paid hires stay candidates.
